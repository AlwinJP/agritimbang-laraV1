AGRITIMBANG - AUCTION SCHEDULE REVISIONS

This is an incremental overlay. Extract/merge its contents into the Laravel project root.
Do not replace the whole project folder.

Changes included:
1. Removed the Register for Auction action from the Farmer Livestock Directory.
   Removed the livestock_id preselection/deep-link behavior from the Farmer Auctions page.
   Actual registration remains available from the Farmer Auctions page and its API; that API
   is still required for the auction registration workflow.
2. Fixed auction registration open/close datetime handling for Philippine time (Asia/Manila).
   Values entered in datetime-local are interpreted as Manila local time, stored as UTC, and
   displayed back in Manila time. Auction lifecycle and registration-open checks also use
   Manila event times consistently.
3. Encoder auction table now shows View Details and View Registrations actions only.
4. View Details displays schedule metadata and creator information, without rendering
   registration rows. Edit, Publish (for drafts), and Cancel actions are inside this details view.
5. View Registrations opens a separate page with paginated farmer, contact, livestock,
   purpose, registration date, registering Encoder, status, and remarks details.
6. Published schedules can now be edited by any authorized Encoder assigned to the same
   municipality. Drafts and published schedules are editable; ongoing, completed, and
   cancelled schedules are locked. Venue/time overlap validation and audit logging remain.
7. Action buttons use green boxed styling; Cancel uses red styling.

Installation:
1. Back up the project files.
2. Extract this ZIP into the Laravel project root and allow files to merge/overwrite.
3. Run:
   php artisan optimize:clear
   npm run build
4. No database migration is added by this overlay.

Important:
- The existing Auction Management migrations from the earlier auction overlay must already
  have been applied.
- The registration API is intentionally retained because farmers still register livestock
  from the Farmer Auctions page; only the direct directory shortcut/preselection is removed.
- The preparation environment passed PHP syntax checks and JavaScript syntax checks.
  Laravel route:list could not run because PHP mbstring is missing in this environment.
  Vite build could not run because the bundled node_modules vite executable is not executable.
  Run the commands in the user's Laragon environment to complete local validation.
