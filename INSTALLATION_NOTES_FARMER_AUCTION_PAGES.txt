AGRITIMBANG — FARMER AUCTION PAGES UPDATE

WHAT CHANGED
1. Farmer Auctions now separates schedules into two sections:
   - Open Registrations: published auctions accepting registrations now.
   - Soon to Open: published auctions whose registration window has not started.
   Open registrations appear first. Schedules with closed registration windows, cancelled schedules, and ongoing/completed auctions are not included in these discovery sections.
2. View Schedule opens a dedicated schedule details page at /auctions/{schedule}.
3. Register Livestock opens a separate page at /auctions/{schedule}/register.
4. The registration page loads only eligible livestock belonging to the signed-in Farmer and displays multi-select cards.
5. Each livestock card displays the uploaded livestock photo when available. If missing or inaccessible, a species-specific placeholder image is displayed.
6. Removed the old ineligible-livestock/needs-attention section and count from the Farmer auction registration UI. Eligibility checks remain enforced by the backend.
7. Updated published-schedule notification links to open the dedicated schedule details page.
8. Kept registration submission on the existing protected API endpoint; ownership, municipality, status, required-field, and duplicate-active-registration checks remain enforced server-side.

INSTALLATION
1. Back up the current project.
2. Extract this ZIP into the Laravel project root and allow files to merge/overwrite.
3. Run:
   php artisan optimize:clear
   npm run build
4. Ensure Laravel's public storage link exists for uploaded livestock photos:
   php artisan storage:link
   Run this only if the storage link has not already been created.
